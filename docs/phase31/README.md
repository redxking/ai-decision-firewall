## Purpose

The Phase 3.1 increment creates the evaluation boundary required before model
complexity increases. It answers whether candidate predictions can be compared
reproducibly under disjoint temporal partitions, calibration and abstention
metrics, subgroup views and explicit evidence limitations. It does not answer
whether the model is operationally effective.

The current mechanism:

1. SHA-256 binds the four committed synthetic source pools.
2. Recombines the historical train/test names as source pools only.
3. Sorts all 1,200 cases by `opened_at` and creates disjoint training,
   calibration and evaluation partitions.
4. Prevents an equal timestamp from crossing a partition boundary.
5. Fits one logistic baseline on training rows only.
6. Fits one Platt calibration challenger on calibration scores and labels only.
7. Evaluates both candidates once on the final temporal partition.
8. Reports discrimination, calibration, threshold, Wilson-interval, selective
   risk and subgroup metrics without case payloads.
9. Returns `NOT_AUTHORIZED` for promotion regardless of observed synthetic
   metric changes.

The committed data was generated by one synthetic scenario family. Temporal
partitioning prevents direct case overlap; it does not create independent
adjudication, source realism, operational representativeness or a valid failure
rate.

## Reproduce the mechanism

Validate the closed plan:

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src \
python3 scripts/run_phase31_model_benchmark.py --validate-plan
```

Run the synthetic benchmark to a new, no-clobber output path:

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src \
python3 scripts/run_phase31_model_benchmark.py \
  --output /tmp/phase31-model-evaluation-result.json
```

Run its focused regression module:

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src \
python3 -m unittest tests.test_phase31_model_evaluation -v
```

## Current synthetic mechanism observation

The fixed plan yields 720 training, 240 calibration and 240 evaluation rows.
The Platt challenger preserved the baseline ranking and threshold confusion
matrix while reducing the synthetic evaluation Brier score by `0.00098425`,
log loss by `0.01113884` and 10-bin expected calibration error by `0.00309615`.
These deltas demonstrate that the comparison path works. They do not establish
practical significance, generalization, superiority or promotion eligibility.

No project document should call the challenger an improved operational model.
