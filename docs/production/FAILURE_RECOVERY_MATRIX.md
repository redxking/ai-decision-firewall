# Stage A Failure and Recovery Matrix

**System state:** production-development candidate
**Scope:** single host, offline, synthetic fixtures, in-memory synthetic target only
**Baseline:** `bb6b8f28afba0961bb97b24e6050fccaa94d5702`

## Safety rule

After a possible effect, the system and operator must report the most conservative supportable state. A broker acknowledgement is not proof of effect; failed readback is not proof of no effect; a described rollback is not an executed rollback; and incomplete audit is not audit closure.

The Stage A durable-attempt states are:

| State | Permitted interpretation |
|---|---|
| `RESERVED` | Execution may be in progress. It is never an operator-approved restart state. |
| `COMPLETED` | The repository-controlled synthetic path recorded its expected terminal outcome. It is not an operational-effect claim. |
| `FAILED_NO_EFFECT` | The tested synthetic path recorded no state change. It is not proof about a real adapter or target. |
| `UNKNOWN_EFFECT` | An effect may have occurred. Automatic retry, replacement authorization, and success claims are prohibited. |

At startup, every durable `RESERVED` attempt must be transactionally changed to `UNKNOWN_EFFECT` before request processing is enabled. This is an explicit operator call under exclusive, quiesced ownership—not an automatic action in every constructor. Reconciliation failure keeps processing disabled.

### Status vocabulary

- `BASELINE_TESTED`: covered by synthetic tests at or before the baseline.
- `STAGE_A_CANDIDATE`: current local durable-ledger increment; exact commit and CI remain required.
- `PARTIAL`: some tested behavior exists, but the production property is incomplete.
- `OPEN`: required behavior or acceptance evidence is absent.
- `NOT_APPLICABLE_BY_PROHIBITION`: the dependency/path is absent because Stage A prohibits it; this is not validation for a later stage.

## Exit criteria for this matrix

This matrix is complete only as a coverage artifact. Stage A remains blocked from production claims until every `OPEN` or `PARTIAL` mandatory property has objective acceptance evidence, the Stage A candidate is frozen to an exact commit, the complete suite and manifest pass on that commit, and accountable owners accept the residual risks.

Passing the listed tests supports only the named synthetic behavior. It does not establish an operational failure rate, production availability, vendor compatibility, independent verification, successful rollback, historical-data safety, or mission acceptance.
